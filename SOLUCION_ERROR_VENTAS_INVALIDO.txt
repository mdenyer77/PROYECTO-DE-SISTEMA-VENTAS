# ?? ERROR: "El nombre de objeto ventas no es válido"

## ¿QUÉ SIGNIFICA ESTE ERROR?

---

## ?? SOLUCIÓN - PASO A PASO

### PASO 1: Abre SQL Server Management Studio
1. Abre **SQL Server Management Studio**
2. Conectate a tu base de datos

### PASO 2: Copia el SQL
Copia TODO este código:

```sql
-- Primero, elimina si existe:
IF EXISTS (SELECT 1 FROM sys.objects WHERE type = 'P' AND name = 'sp_ListarVentasConCliente')
BEGIN
    DROP PROCEDURE sp_ListarVentasConCliente
END
GO

-- Ahora crea el procedimiento:
CREATE PROCEDURE sp_ListarVentasConCliente
AS
BEGIN
    SELECT 
        v.ID_venta,
        v.Fecha_venta,
        c.ID_cliente,
        c.Nombre AS Cliente_Nombre,
        c.Telefono AS Cliente_Telefono,
        c.Direccion AS Cliente_Direccion,
        v.Total_general,
        CASE WHEN v.Estado_venta = 1 THEN 'Activa' ELSE 'Cancelada' END AS Estado_venta
    FROM Ventas v
    INNER JOIN Cliente c ON v.ID_cliente = c.ID_cliente
    ORDER BY v.Fecha_venta DESC
END
GO
```

### PASO 3: Pega en SQL Server
1. En SQL Server Management Studio, crea una **Nueva consulta**
2. Pega el código
3. Presiona **Ejecutar** (F5)

### PASO 4: Verifica que se creó
Ejecuta esto en una nueva consulta:

```sql
SELECT * FROM sys.objects WHERE type = 'P' AND name = 'sp_ListarVentasConCliente'
```

Deberías ver una fila con el procedimiento.

### PASO 5: Prueba el procedimiento
Ejecuta esto:

```sql
EXEC sp_ListarVentasConCliente
```

Deberías ver tus ventas (si existen en la BD).
